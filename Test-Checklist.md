# Manual Testing Checklist — Login Page

- [ ] Login page loads without layout errors.
- [ ] Username and password fields are present.
- [ ] Login button is visible and usable.
- [ ] Valid test credentials allow login.
- [ ] Invalid credentials do not allow login.
- [ ] Blank username/password validation works.
- [ ] Password is masked by default.
- [ ] Password visibility toggle works, if provided.
- [ ] Forgot Password opens the correct flow.
- [ ] Error messages are understandable and accessible.
- [ ] Keyboard navigation works.
- [ ] Supported viewport sizes are usable.
- [ ] Logout works.
- [ ] Protected pages require authentication.
- [ ] Results and evidence are recorded accurately.
