# Manual Testing Project — Login Page

## Project overview
This beginner-friendly portfolio project demonstrates manual testing documentation for a sample web application's login and password-recovery flows.

**Important:** This is a practice project. The test cases and bug reports are examples, not results from testing a real application. Update the Actual Result and Status fields after testing a real application.

## Objectives
- Prepare test scenarios and test cases.
- Cover positive, negative, validation, and usability checks.
- Document sample defects clearly.
- Summarize test execution results.
- Practice organizing QA documents in GitHub.

## Scope
- Login with valid and invalid credentials
- Required-field validation
- Password masking
- Forgot-password navigation
- Logout behavior (after successful login)
- Basic usability and session checks

## Test environment (example — replace with your actual environment)
- Application: Demo login page / practice application
- Browser: Chrome (record your version)
- Operating system: Windows 10/11
- Test type: Manual functional testing
- Test data: Dummy credentials only; never commit real passwords or personal data

## Repository structure
- `test-cases/Test-Cases.xlsx` — test cases and execution fields
- `test-cases/Test-Cases.csv` — same test cases in CSV format
- `bug-reports/Bug-Report.xlsx` — sample defect log
- `bug-reports/Bug-Report.csv` — same sample defects in CSV format
- `test-summary/Test-Summary.md` — execution summary template
- `test-summary/Test-Checklist.md` — quick testing checklist
- `screenshots/README.md` — guidance for adding screenshots safely

## How to use
1. Choose a demo application that you are allowed to test.
2. Review each test case and replace the sample test data as needed.
3. Execute each test manually.
4. Fill in **Actual Result**, **Status**, and **Evidence** fields based on what really happened.
5. Create a bug report only when you observe a reproducible defect.
6. Update the test summary with actual counts and results.
7. Upload the folder to GitHub.

## How to upload to GitHub (web interface)
1. Sign in at https://github.com/
2. Create a repository named `Manual-Testing-Project`.
3. Choose Public only if you are comfortable sharing the contents.
4. In the repository, choose **Add file → Upload files**.
5. Upload the project files/folders and select **Commit changes**.
6. Open the repository and copy its URL for your resume.
